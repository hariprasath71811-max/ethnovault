EthnoVault · EthnoHack 2026
The Problem

Oral knowledge disappears when it is extracted without consent.

Disappearing knowledge

UNESCO estimates a language dies every two weeks. Plant wisdom, songs, and ecological calendars live in elders' voices — not in databases.

Extractive archives

Most archives record first and ask later: no attribution, no reuse terms, no withdrawal. Communities lose control of their own heritage.

No FPIC in tooling

Free, Prior and Informed Consent is a legal principle, but almost no software enforces it at the media layer.

Verification gap

There is no lightweight way for elders and culture-bearers to review, endorse, or reject a record before it goes public.

EthnoVault · EthnoHack 2026
The Solution

Ethical ethnopharmacology + an acoustic, community-governed archive.

Consent-first by design

Every record carries attribution, community, region, license tier (listen-only / educational / community-internal) and an explicit consent flag. Nothing publishes without quorum.

Acoustic Oral Studio

Waveform visualizer, scrubber, transcript-synced seeking, speed control, and a Web Audio harmonic synthesizer for language-learning playback.

Elder Council verification

A 3-endorsement quorum from elders and culture-bearers publishes a record. Communities can withdraw at any time.

Guided submission pipeline

Knowledge type, origin community, attribution, story, optional voice recording, and consent — in one flow. New records enter a pending queue.

Technical Architecture

Three static files. No backend. No tracking.

Frontend

index.html + styles.css + app.js. Tailwind CSS (CDN), Lucide icons, Google Fonts, Unsplash imagery. State persisted in localStorage.

Audio layer

Web Audio API harmonic synthesizer + Canvas waveform renderer. Real-time playhead, scrubbing, speed control, transcript-synced seeking.

Rendering

Vanilla JS SPA with hash-free in-page navigation, IntersectionObserver reveals, requestAnimationFrame counters, responsive grid (390–1440 px).

Deployment

GitHub Pages (static). Automated demo recording with Playwright + ffmpeg (H.264, 83.8 s). Zero build step, zero dependencies at runtime.

EthnoVault · EthnoHack 2026
Elder Council Verification

Nagoya Protocol & FPIC compliance, built into the workflow.

  • Quorum: 3 endorsements from elders + culture-bearers required to publish.
  • Pending queue: every submission starts pending; never auto-published.
  • Attribution: knowledge keepers named on every record, with reuse terms.
  • Withdrawal: communities can withdraw a record at any time (deletion tooling on roadmap).
  • Privacy tiers: listen-only, educational, community-internal — enforced at the media layer.
  • Auditability: endorsement events are visible and traceable in the council view.

Limitations · Responsible Research · Roadmap

Honest about what's simulated. Clear about what's next.

Limitations (simulated)

  • Audio, uploads, translations, endorsements, council actions run in-browser
  • Records are illustrative composites, not real community knowledge
  • No real identity, auth, or encrypted storage yet

Responsible research

  • Consent-first, attribution on every record
  • Community-controlled reuse tiers
  • No extraction, no tracking, no surveillance

Roadmap

Encrypted community-held media storage · Offline-first PWA for low-connectivity regions · Production council identity & audit trails · True withdrawal/deletion tooling · Time-aligned transcripts & pronunciation guides · Multi-language interfaces · Partnerships with language nests & seed keepers.
